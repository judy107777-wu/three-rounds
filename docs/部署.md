# 部署到 GitHub Pages

> 這一份是 T18 的步驟說明。實際的建立 repo、推上去、實機驗證需要你自己操作。

## 一、把專案放上 GitHub

在專案資料夾裡：

```bash
git init
```

```bash
git add .
```

```bash
git commit -m "三遍練習：第一版"
```

到 GitHub 開一個新的 repository（Public 或 Private 都可以，Private 需要付費方案才能開 Pages），
然後把本機接上去並推上去。`你的帳號` 與 `你的repo名` 換成實際的：

```bash
git remote add origin https://github.com/你的帳號/你的repo名.git
```

```bash
git branch -M main
```

```bash
git push -u origin main
```

## 二、打開 GitHub Pages

1. 進到該 repository → **Settings** → 左邊選單 **Pages**
2. **Source** 選 `Deploy from a branch`
3. **Branch** 選 `main`、資料夾選 `/ (root)` → **Save**
4. 等一兩分鐘，頁面上方會出現網址：`https://你的帳號.github.io/你的repo名/`

`node_modules` 不會被推上去（`.gitignore` 已經擋掉），Pages 也不需要它——
整個 APP 是純網頁，沒有建置步驟。

## 三、加到手機主畫面

用 Android Chrome 打開上面那個網址：

1. 右上角「⋮」→ **加到主畫面**
2. 桌面會出現一個奶茶棕的圖示
3. 點開是全螢幕，沒有網址列

> 必須是 `https://` 才會有這個選項，也才允許錄音。GitHub Pages 本來就是 https，沒問題。

## 四、實機驗收（照著跑一次）

| 檢查 | 怎麼算過 |
| --- | --- |
| 全部測試 | `npm test` 全過 |
| 麥克風 | 第一次按「開始第 1 遍」時跳出權限詢問，按允許 |
| 完整流程 | 三遍都講完 → 補標題 → 存檔 |
| 資料還在 | 把 APP 關掉再打開，剛才那筆在歷史紀錄裡 |
| 中斷續接 | 只講第 1 遍就關掉，再打開時停在「開始第 2 遍」 |
| 搜尋 | 用逐字稿裡的某個詞搜尋，找得到那一筆 |
| AI 檢查 | 設定頁貼上金鑰後，按「做 AI 檢查」出現四個區塊 |
| 離線 | 開飛航模式再打開 APP，畫面正常；按 AI 檢查會提示需要連網 |
| 桌面圖示 | 從桌面圖示打開是全螢幕 |

## 之後要改版

改完程式碼後：

```bash
git add . && git commit -m "說明改了什麼" && git push
```

推上去一兩分鐘後生效。手機端因為有離線快取，可能需要關掉 APP 再開一次才會拿到新版
（`sw.js` 裡的 `CACHE_NAME` 改個版號可以強制更新）。桌面圖示不用重裝。
