# 需求：日常表達力 3 遍極簡練習 APP

> 日期：2026-08-27 ｜ 狀態：待確認

## 1. 一句話目標

每天在手機上花 15 分鐘，用同一主題連續講三遍的方式，改善「講話被分支帶走、失去重點」的問題。

## 2. 定位

- 面向：2C，個人自用，單人使用
- 產業背景：使用者經營親子烘焙教室，具教學經驗
- 分享為後續選項，前提是自己先能持續使用；順利的話才考慮開放給教室老師或學員

## 3. 為什麼要做

**為什麼是現在**

- 說話沒有重點是長期困擾，不是突然出現的需求
- 近期看到一支影片提出具體可執行的練習方法（同一主題講三遍、時間遞減），判斷可行
- 這個題目同時可以當作程式開發的練習題

**現在哪裡不舒服**

- 準備過的場合沒有問題。上課內容經過多次提煉，重點清楚
- 出問題的是即興、無稿的閒聊溝通
- 具體症狀：描述看過的一篇文章或一件事時，腦中會胡亂跳出各種分支把主題帶走，說話重點飄移，最後連自己都忘記當初為什麼提起這個話題

**不做會怎樣**

- 朋友通常不會直接反應，但使用者能感覺到對方興趣流失
- 家人與親近朋友會直接反問「你的重點是什麼」「你到底要說什麼」
- 痛感同時來自外部回饋與自我察覺

## 4. 理想畫面

聊天時能把一件事一路講完，不被腦中的分支帶走。

## 5. 使用場景

| 項目 | 內容 |
| --- | --- |
| 誰用 | 使用者本人 |
| 什麼時候 | 時間不固定，但當天睡前必須完成 |
| 什麼場合 | 教室收工後、通勤途中、家裡皆有可能 |
| 共同條件 | 身邊沒有其他人的時候 |
| 當下在做什麼 | 拿當天想分享的文章、影片內容，或當天發生的一件事作為練習素材 |
| 多常發生 | 每天一次 |
| 裝置 | 手機（因地點不固定，必須能在手機上完成整套流程） |

**真實發生過的場景**

使用者在跟朋友描述自己看過的一篇文章時，腦中不斷冒出與主題無關的分支，講著講著重點飄移，結束時自己也想不起來最初為什麼要提這篇文章。朋友沒有明說，但可以感覺到興趣已經流失。

**三遍練習後的檢查需求**

三遍講完之後，希望有 AI 針對三遍內容做一次檢查。原因是精煉的過程中可能會把不該刪的內容一起刪掉，靠自己回頭比對很難察覺。檢查的用途是指出遺漏與偏移，不是評分，也不是代為改寫。

## 6. 也希望派得上用場的其他情況

- 有實際要談的事情時，直接把它當成當天的練習素材，不另外設計模式或流程
- 除此之外沒有其他使用時機。打開這個 APP 就是為了練習

## 7. 這次明確不做

- 提醒、通知
- 連續天數統計、打卡紀錄
- 註冊、登入、帳號綁定
- 雲端上傳，或任何他人可見的儲存方式
- 分數、等第、評比排名
- 鼓勵性評語
- 動畫特效
- 題庫、主題建議
- AI 代寫範例稿或示範講稿（會導致背稿，違背練習目的）

原則：先做最單純的版本，實際用過再說。

## 8. 尚未確認

- 使用者尚未實際執行過完整的每日三遍練習，計畫先實用一週，再回頭優化與補充
- 因此第一版應為最小可用版本，避免先做進去的功能後來用不到
- 一週試用後需要重新檢視的項目：練習流程是否順手、AI 檢查的內容與篇幅是否合用、有沒有實際上根本不會用到的功能
